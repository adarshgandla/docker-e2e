Act 1: CLI Primitives 00-03 min
1.1 The 4 Pillars
Say: "Dockerfile = recipe, Image = frozen cake, Registry = warehouse, Container = running cake."
docker images
1.2 Pull Image
Say: "Pull downloads frozen layers without running."
docker pull nginx
1.3 Detached Run (-d -p)
Say: "-d runs as background daemon; gives terminal back immediately."
docker run -d -p 8080:80 --name demo-web nginx
👁️ Verify: http://localhost:8080
1.4 Inspect Logs
Say: "Since -d is silent, docker logs peeks inside."
docker logs demo-web
1.5 Stop & Prune
docker stop demo-web; docker rm demo-web; docker system prune -a -f
Act 2: Track 1 Monolith 03-08 min
2.1 Cd to Monolith
cd 01-single-container
2.2 Build Image
Say: "Stage 1 builds Vite; Stage 2 serves Express + SQLite and drops root to 1001."
docker build -t taskflow-single:1.2.0 .
2.3 Run with Volume
Say: "Host port 5000 -> 4000. Volume taskflow_data saves SQLite across deletions."
docker run -d -p 5000:4000 -v taskflow_data:/data --name taskflow_app taskflow-single:1.2.0
👁️ UI: http://localhost:5000
2.4 Test Persistence
Say: "Delete container and remake it. Tasks stay intact due to volume!"
docker rm -f taskflow_app; docker run -d -p 5000:4000 -v taskflow_data:/data --name taskflow_app taskflow-single:1.2.0
Act 3: Track 2 Microservices 08-14 min
3.1 Navigate
Say: "No more long CLI flags. Compose declares everything in YAML."
cd ../02-multi-container
3.2 Up Entire Mesh
Say: "1 command starts React UI, Express API, Postgres DB, and Redis cache."
docker compose up -d --build
👁️ UI: :3000 | API: :4000/api/health
3.3 Check Internal DNS
Say: "Express connects to 'postgres' and 'redis' by service name. Embedded DNS resolves them."
docker compose ps; docker compose logs -f backend
3.4 Teardown
docker compose down
